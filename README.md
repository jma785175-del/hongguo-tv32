# 红果大屏 1.0.12-tv32

个人电视客户端，Android 7.0+，支持 32 位 ARM 电视。包名 com.local.hongguo.tv。

深色界面、粉红焦点、左侧导航；支持推荐、找剧、分类、排行榜、本机收藏和历史。方向键移动、确认打开、返回退出当前层级；播放中确认暂停/继续，左右快退/快进，上键播放选项，下键选集。搜索支持拼音首字母和手机输入。

## 播放与兼容

剧集详情新增「下载全集」，侧栏新增「下载」。支持单线程后台下载、暂停、继续、断点续传、删除单集和删除整部下载。在线播放优先，观看时暂停下载，停止观看后继续；下载保留至少 512 MB 剩余空间，空间不足或来源失败时暂停并显示原因。可从下载管理选择已完成的分集离线观看，正常选集时也优先播放本地文件。

下载保存在应用专用目录，不需要读取相册或公共存储权限。单集完成后才可离线观看；未完成文件以分段形式保存，下次根据视频长度及文件头摘要校验续传。同一任务中删除的分集不会自动重新下载；再次点击「下载全集」可补回。删除下载不影响收藏和观看记录。卸载应用或清除应用数据会清理这些本地文件；电视重启、系统强制停止后，需要打开下载管理继续任务。

内容目录基于 fyworld/hongguoTV 的 Kotlin 实现。播放优先使用本版修复的签名接口，openhongguo 0.2.0 作为原有线路保留。当前集和下一集预加载共用所选播放源。

播放页、播放失败页、剧集详情和设置页均可选择播放源。默认自动尝试多条线路，手动选择后使用该线路，切源保留当前集与位置。线路一至六为同一平台的不同接口主机，原有线路和网页线路保留供手动检查。菜单显示本次运行中各线路上一次请求的结果。

接口出现 HTTP 200 空响应时，前台尝试更新失效的匿名会话并重试一次，最多每分钟触发一次更新。后台预加载只试一条线路，失败时结束本次预加载。只有视频头和分段读取成功后才把线路记为成功，媒体地址无法读取时尝试接口提供的备用地址，再按自动模式切换接口。

2026 年 11 月 11 日更新了播放请求签名，实现来自 openhongguo PR 7 的 Kotlin 移植。该变更用于恢复播放接口的空响应问题。完整来源和许可证见 NOTICE.md。

当前集稳定播放、预计剩余时间进入 60 秒后，低优先级后台线程会准备下一集的播放信息并缓存开头约 1 MiB。自动连播和遥控器手动切到下一集都能复用缓存。按流量计费的网络跳过预加载，当前集暂停或卡顿时取消仍在进行的预加载。

播放中持续卡顿 10 秒，或同一画质连续两次解码失败时，自动尝试低一档并从保存的位置继续。降档只用于当前集，切换下一集时恢复默认清晰度。

剧集详情和播放中的选集面板会显示「已看」「未看完」「未看」。选择「首个未看」可把遥控器焦点移到对应集，选中未看完的一集可续播。旧版已有的最近一集记录仍可识别，分集记录可随手机备份导出和恢复。

APK 包含 ARMv7（32 位）、ARM64、x86、x86_64 原生库。Android 8.0 及以上的 32 位系统使用独立进程中的 VLC 软件解码，最高 720P，亦可手动选择 480P。解码进程退出后，主界面保存观看位置并提供重试。Android 7 系列继续使用系统软件解码，64 位系统继续使用默认解码选择。

## 构建

JDK 17；Android SDK Platform 36；Build Tools 36.1.0。创建 local.properties，写入 sdk.dir=SDK绝对路径（Windows 建议用正斜线）。

```powershell
.\gradlew.bat :core:test :app:assembleRelease --no-daemon --max-workers=2
```

输出 app/build/outputs/apk/release/app-release.apk。自用签名通过 keystore.properties 提供 storeFile、storePassword、keyAlias、keyPassword；未提供时使用本机 debug 签名。交付 APK 使用独立个人签名，私钥没有放入源码包。
